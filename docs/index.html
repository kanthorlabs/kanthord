current scope

The reference describes implemented behavior, not the full proposed product. The CLI and the API cover configuration, tokens, the Gateway, the LLM, repository and storage credentials, agents, projects, missions, the Scheduler and workers. The Tracking CLI group exposes help only. serve server runs the server; serve worker registers a worker instance, pulls work and executes it.

Internal design discussions and source-level implementation notes are not part of this site.
