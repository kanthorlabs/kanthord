Engine documentation

This site documents the kanthord engine — the daemon, its HTTP API, and its data model. The frontend application has its own documentation.

Start with Overview for orientation. Read Conventions to understand status annotations and link policy before citing anything from these pages.

Follow one task through the engine — a guided reading path

  1. System map stub Understand what kanthord is and what talks to what before reading anything else.
  2. Identity and access stub Establish who the actors are and how they prove identity.
  3. Setup and registration stub Create the provider, project, and repository that every task depends on.
  4. Work graph stub Import a plan; watch it become nodes and edges in the graph.
  5. Who does the work stub Follow a harness as it claims a task, runs its agent loop, and reports back.
  6. State and completion stub Trace every legal state transition from pending to a terminal state.
  7. Recovery and troubleshooting stub Diagnose a stuck or crashed task; understand what startup recovery does.
  8. Capability status stub Check which capabilities are real, which are stubbed, and which are undecided.
  9. Reference stub Look up exact tables, HTTP operations, and CLI commands.
