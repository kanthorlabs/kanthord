- [ ] RULED 2026-10-20 by Ulrich (Group B, worker instance model). KanthorD has no host, machine or runner concept. A human registers an instance once on the server. A `worker` placement binding of any project names its registered instances in the field `worker_instances`, in place of `instance_count`. `instance_count` stays for the `server` and `container` placements.
