Workbench operation tools

An agent of a Workbench session can call 137 KanthorD operations as tools. 60 of them change state and wait for the approval of the human. How the native agent works explains the selection rule and the exclusions.

The tool name is the operation id with each . replaced by --. A tool runs with the identity of the human who sent the last message.
