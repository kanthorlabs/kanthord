Workbench operation tools

Each Workbench agent holds only the operation tools that its declaration lists. A tool that changes state waits for the approval of the human. How the native agent works explains the selection rule and the exclusions.

The tool name is the operation id with each . replaced by --. A tool runs with the identity of the human who sent the last message.
