Agent variants

Function description

An agent variant is a named role of one Workbench session agent. It holds its own display name and its own instruction. Every other property comes from the base agent: the tools, the enablement, the agent providers, the default configuration, the base prompt parts and the guard.

A session of a variant composes the Workbench system prompt of the base agent with the part variant. That part holds the instruction only. See the agent view. A change of the name or of the instruction applies at the next agent session.

The base agent is swe@1, re@1, ops@1 or plan@1. A variant of guard@1 or of any other agent is refused. The display name holds 1 to 40 characters of [A-Za-z0-9 _-], starts with a letter and has no leading, trailing or double space. It is unique, case-insensitively, among the display names of the catalog and of the variants.

The instruction is not blank and holds at most 32768 UTF-8 bytes. A used variant cannot be deleted. A delete is refused while an open session holds the variant. It is also refused while the session directory of the variant holds a session file. A delete removes an empty session directory of the variant. A human renames the variant or rewrites its instruction instead.

The dashboard calls these operations. They have no CLI command.

Operation Effect
agent.variant.list Read every variant, with no instruction.
agent.variant.get Read one variant with its instruction.
agent.variant.create Create a variant of one base agent.
agent.variant.update Replace the display name and the instruction at the expected revision.
agent.variant.delete Delete a variant at the expected revision, when no open session holds it and its session directory holds no session file.

Expected response

agent.variant.list

The API returns HTTP 200.

{
  "items": [
    {
      "id": "agent_variant_01M4C5G6DGWEVZYSPETSQR65JH",
      "agent_name": "ops@1",
      "display_name": "Night Ops",
      "revision": 1
    }
  ]
}
Property Type Purpose
items array Every variant, ordered by agent_name, then by display_name. The list has no pagination.
items[].id string Variant identity, agent_variant_<ulid>.
items[].agent_name string Base agent. It never changes after the create.
items[].display_name string Variant name.
items[].revision positive integer Starts at 1. Each update adds 1.

agent.variant.get

The API returns HTTP 200 with the variant.

{
  "id": "agent_variant_01M4C5G6DGWEVZYSPETSQR65JH",
  "agent_name": "ops@1",
  "display_name": "Night Ops",
  "instruction": "Keep answers short and watch for blocked work.",
  "revision": 1
}
Property Type Purpose
id string Variant identity, agent_variant_<ulid>.
agent_name string Base agent. It never changes after the create.
display_name string Variant name.
instruction string Variant instruction.
revision positive integer Starts at 1. Each update adds 1.

agent.variant.create

The API returns HTTP 200 with the new variant. Its revision is 1. 

{
  "id": "agent_variant_01M4C5G6DGWEVZYSPETSQR65JH",
  "agent_name": "ops@1",
  "display_name": "Night Ops",
  "instruction": "Keep answers short and watch for blocked work.",
  "revision": 1
}

agent.variant.update

The API returns HTTP 200 with the changed variant. Its revision is the expected revision plus 1. 

{
  "id": "agent_variant_01M4C5G6DGWEVZYSPETSQR65JH",
  "agent_name": "ops@1",
  "display_name": "Night Shift",
  "instruction": "Keep answers short and watch for blocked work.",
  "revision": 2
}

agent.variant.delete

The API returns HTTP 200 with the deleted identity. 

{ "id": "agent_variant_01M4C5G6DGWEVZYSPETSQR65JH" }

Failures

API failures use the shared error envelope.

HTTP status / code Operations Meaning
401 gateway.authentication.unauthorized All Missing, invalid, expired or banned token, or a machine token.
400 gateway.request.validation_failed All A path parameter, the query or the body fails the schema. A blank instruction, or one above 32768 UTF-8 bytes, fails it with details path ["body", "instruction"]. No code is specific to the instruction.
400 gateway.request.unexpected_body list, get The request has a body.
400 gateway.idempotency.invalid_key create, update, delete Missing or malformed idempotency key.
409 gateway.idempotency.conflict create, update, delete The key belongs to a different request of the same caller.
404 agent.catalog.not_found create agent_name is not in the catalog.
404 agent.variant.not_found get, update, delete variant_id names no variant.
409 agent.variant.base_refused create The agent has no Workbench session, for example guard@1 or pe@1.
400 agent.variant.name_invalid create, update display_name breaks the name rule: 1 to 40 characters of [A-Za-z0-9 _-], a letter first, and no leading, trailing or double space.
409 agent.variant.name_taken create, update display_name equals, case-insensitively, the display name of a catalog agent or of another variant.
409 agent.variant.revision_conflict update, delete expected_revision is stale. details holds { variant_id, current }, and current is the current variant.
409 agent.variant.in_use delete An open session holds the variant, or the session directory of the variant holds a session file.
504 gateway.invocation.timeout All The operation exceeded 30 seconds.

API shape

All operations use human access, a 30-second timeout, and the header Authorization: Bearer <human-jwt>. The operations create, update and delete also require an Idempotency-Key header with a fresh idempotency_key_<ulid>.

Operation ID Method and path Body Mutation
agent.variant.list GET /api/agent/variant None No
agent.variant.get GET /api/agent/variant/:variant_id None No
agent.variant.create POST /api/agent/variant { agent_name, display_name, instruction } Yes
agent.variant.update PUT /api/agent/variant/:variant_id { display_name, instruction, expected_revision } Yes
agent.variant.delete DELETE /api/agent/variant/:variant_id { expected_revision } Yes

The static path /api/agent/variant does not match GET /api/agent/:agent_name. Every body is a strict object: an unknown key fails the schema. 

curl -s http://127.0.0.1:31415/api/agent/variant \
  -H 'Authorization: Bearer <human-jwt>'

curl -s http://127.0.0.1:31415/api/agent/variant/agent_variant_01M4C5G6DGWEVZYSPETSQR65JH \
  -H 'Authorization: Bearer <human-jwt>'

curl -s -X POST http://127.0.0.1:31415/api/agent/variant \
  -H 'Authorization: Bearer <human-jwt>' \
  -H 'Idempotency-Key: idempotency_key_01M34JC4BJ66JHP41M4MYY6PST' \
  -H 'Content-Type: application/json' \
  -d '{"agent_name":"ops@1","display_name":"Night Ops","instruction":"Keep answers short and watch for blocked work."}'

curl -s -X PUT http://127.0.0.1:31415/api/agent/variant/agent_variant_01M4C5G6DGWEVZYSPETSQR65JH \
  -H 'Authorization: Bearer <human-jwt>' \
  -H 'Idempotency-Key: idempotency_key_01M34JC4BJ66JHP41M4MYY6PSV' \
  -H 'Content-Type: application/json' \
  -d '{"display_name":"Night Shift","instruction":"Keep answers short and watch for blocked work.","expected_revision":1}'

curl -s -X DELETE http://127.0.0.1:31415/api/agent/variant/agent_variant_01M4C5G6DGWEVZYSPETSQR65JH \
  -H 'Authorization: Bearer <human-jwt>' \
  -H 'Idempotency-Key: idempotency_key_01M34JC4BJ66JHP41M4MYY6PSW' \
  -H 'Content-Type: application/json' \
  -d '{"expected_revision":2}'
