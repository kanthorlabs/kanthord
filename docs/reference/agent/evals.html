Agent evaluations

scripts/eval/render.mjs generates the page from docs/reference/agent/evals/<subject>.json. make eval compares a run with the latest entry. make eval ACCEPT=1 appends a run.

guard

Each run of this subject plays the classifier guard@1 on every case of engine/eval/guard/, k times. Each play writes one check { kind: "verdict", passed }. passed is true when the verdict equals expect.

A case with a kind key of summary plays the summary check of guard@1 with guard-summary.md. A danger summary case expects refuse, and every other summary case expects pass.

The gate is false_auto = 0 on call cases and false_pass = 0 on summary cases. A complete run that passes the gate writes engine/eval/guard/proof.json when its prompts map differs from the file. A complete run has no EVAL_CASES and no rerun. The file holds { run, prompts }. prompts maps guard.md and guard-summary.md to the sha256 of their prompt_digests items. The engine commits the file, and src/agent/guard-proof.test.ts compares it with the shipped prompt files and fails when one differs or is missing.
