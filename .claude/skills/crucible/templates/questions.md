# Questions for the reader test

1. <Definition question: how do term A and term B differ? Ask for one concrete example of each.>
2. <Lifecycle question: trace X from the first state to the last. Name each state, the actor and the event.>
3. <Scenario question: event E happens at moment M. What does the system do, which exact payload does it send, and what is the next state?>
4. <Limit question: which default value applies, which count it uses, and what happens at the limit?>
5. <State question: list every place where the state lives between two executions.>
6. <Setup question: what must an operator configure, run and install?>
7. <Recovery question: after failure F, what happens at the next run, and how does a human recover?>
8. <Why question: why does rule R exist, and what breaks without it?>
