## 2026-07-31 — S8 Phase C race condition fix

- **Decision:** Prefetch `healthQueryOptions()` in `main.tsx` using top-level `await` before `createRoot().render()`.
- **Why:** The TE diagnosed that React's concurrent rendering commits the `async-resolved` wrapper div before its children when a query transitions from loading→resolved. By prefetching into the QueryClient cache before mount, `useQuery` returns cached data on first render — no state transition, no split commit.
- **Alternatives considered:** Route `loader` (rejected: requires changing `createAppRouter` signature which the test calls without args), React Suspense (rejected: more invasive restructuring). Prefetch in `main.tsx` is the smallest surgical change.
